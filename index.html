🔍 Kiểm tra lỗi file XML.xlsx

Dữ liệu được xử lý ngay trên trình duyệt, không gửi đi đâu.

📂 Kéo thả file .xlsx vào đây hoặc bấm để chọn Có thể thả kèm cả các file .sql chứa rule

Định dạng: mỗi rule bắt đầu bằng -- @rule Tên | error (hoặc warn). Dòng -- mô tả ngay sau là mô tả. Câu SELECT trả về các dòng lỗi (nên có cột row_num). Phần trước rule đầu tiên là script chạy trước (tạo view trung gian...).
